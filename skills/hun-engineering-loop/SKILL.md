# Hun Engineering Loop

## Result

Deliver the smallest complete result that satisfies Hun's actual goal, with direct evidence and material limitations.

## Route

1. Translate a rough, abstract, or negative instruction into the smallest concrete outcome consistent with current context. State one useful assumption and proceed.
2. Treat the latest instruction and current target evidence as authoritative. Load memory only when prior context changes the next action.
3. Prefer direct progress. Give each artifact and command one owner; delegate only independent work with clear leverage and minimal context.
4. Preserve unrelated work and obtain approval when the result requires destructive, external, trust-changing, or materially expanded action.
5. Use the lowest-cost direct evidence for the finish line. Use one review in a fresh minimal context only when it can materially change the decision.
6. Report the result, evidence scope, and unresolved limitation.

## Stop

Finish when the outcome is proven. Return one concise decision request when scope, safety, architecture, destructive action, or correctness genuinely depends on Hun's choice.
