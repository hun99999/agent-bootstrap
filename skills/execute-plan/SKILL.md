# Execute Plan

## Result

Deliver every in-scope plan outcome with its stated evidence, or return the first concrete blocker and the remaining outcomes.

## Route

1. Treat the plan's goals, constraints, approvals, and evidence as the execution contract.
2. Identify the next unmet outcome and inspect only the current source needed for that outcome.
3. Implement the smallest complete change that reaches it. Adapt obsolete procedural detail to current evidence while preserving the approved result.
4. Run the evidence named by that outcome, limited to checks invalidated by the change.
5. Continue through dependent outcomes while progress is concrete.
6. Report delivered outcomes, changed artifacts, evidence, and remaining work.

## Stop

Return to the user when current evidence requires a material architecture or scope decision, a risky action lacks authority, or a blocker prevents the next outcome. Include the exact decision or condition needed to resume.
